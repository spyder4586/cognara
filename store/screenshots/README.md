# Screenshots (1280×800)

Chrome Web Store wants 1280×800 (or 640×400) captures. The two PNGs next to this file are **placeholders** at exactly 1280×800 — replace them with real captures before submission, keeping the filenames and size.

## What to capture

1. `screenshot-1-home-1280x800.png` — YouTube Home with Cognara Enabled: calm home, no Shorts shelves. Caption idea: "Home without Shorts shelves".
2. `screenshot-2-popup-1280x800.png` — Same page with the Cognara popup open (logo + Hide Shorts toggle on). Caption idea: "One toggle. No data collected."

Optional third: search results with no Shorts tiles.

## How

1. 1280×800 window (DevTools device toolbar or resize to exactly 1280×800).
2. Fresh profile, extension installed, Enabled on.
3. Hide bookmarks/history; avoid personal data in frame.
4. Capture Home, then popup open. Overwrite the placeholder files in place.

Do not submit the placeholders — store review rejects non-representative images.
