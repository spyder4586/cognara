# Cognara

Cognara is a minimal blocker that removes YouTube Shorts from desktop YouTube for a calmer viewing environment.

## Language

**Shorts surface**:
A YouTube area where Shorts appear: home shelf, sidebar entry, search results, channel tab or shelf.
_Avoid_: Shorts feed, Shorts section

**Hide**:
Suppression of Shorts surfaces so they are not visible, with underlying YouTube otherwise unchanged.
_Avoid_: Block, remove, redirect, filter

**Enabled**:
The single on/off state; when on, Shorts are hidden, when off, YouTube appears untouched.
_Avoid_: Active, on/off toggle state
